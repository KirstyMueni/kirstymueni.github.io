Project Overview

Designed and developed a cross-platform fitness application, applying mobile UX principles and a structured app architecture to deliver a smooth, intuitive user experience. The project focused on turning a clear product idea — helping users track and stay consistent with fitness activity — into a usable, well-organised mobile app.

From screen design to feature implementation, the emphasis was on clarity and ease of use: an interface that feels natural on a phone and an architecture that keeps the code organised as features grow.

Key Focus: Delivering an intuitive, cross-platform mobile experience with clean UX and a structured, maintainable architecture.
