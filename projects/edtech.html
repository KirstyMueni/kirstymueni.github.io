Interactive Classroom Technology Integration Project

EdTech & STEM · PhET / Interactive Tools · Lewa Wildlife Conservancy

Project Overview

Supported the integration of interactive classroom technologies within learning institutions supported by Lewa Wildlife Conservancy, with a focus on turning abstract STEM topics into experiences learners could see, touch, and manipulate.

Tools such as PhET interactive simulations were woven directly into lessons so that concepts in maths and science became visual and hands-on, raising both engagement and understanding in the classroom.

Key Focus: Replacing passive lectures with interactive, hands-on STEM experiences through classroom technology.

Key Responsibilities

  • Integrated PhET interactive simulations into science and maths lessons.
  • Set up and demonstrated interactive classroom tools and displays.
  • Trained teachers to confidently use interactive technology in daily teaching.
  • Aligned interactive resources with curriculum topics and learning goals.
  • Gathered learner and teacher feedback to refine how tools were used.
  • Provided in-class troubleshooting so lessons ran without disruption.

Systems & Technologies Integrated

  • PhET Interactive Simulations
  • Interactive Displays
  • Kolibri / ARES Offline Access
  • Laptops & Tablets
  • Classroom Projection
  • Collaboration Platforms

Tools & Technologies Used

PhET Interactive Simulations Interactive Displays Kolibri / ARES Laptops & Tablets Google Workspace Tools

Integration & Facilitation Activities

  • Mapping simulations to curriculum topics and learning goals
  • Setting up and demonstrating interactive tools in class
  • Training teachers for confident independent use
  • Running lessons alongside teachers and troubleshooting live
  • Collecting feedback to refine tool usage
  • Documenting simple guides for repeat use

Impact & Outcomes

  • Noticeably higher classroom engagement during STEM lessons.
  • Abstract concepts became tangible and easier to grasp.
  • Teachers gained confidence to use interactive tools independently.
  • Richer, more memorable learning experiences for learners.

Project Evidence

Skills Demonstrated

  • Interactive Classroom Integration
  • STEM Facilitation
  • PhET Simulation Use
  • Teacher Training & Coaching
  • Curriculum Alignment
  • In-Class Troubleshooting

Project Outcome

This project strengthened practical experience in bringing interactive technology into everyday STEM teaching. It also enhanced the ability to support teachers in adopting hands-on tools confidently, so that classrooms moved from passive instruction to active, technology-enabled learning that learners could see and shape for themselves.
