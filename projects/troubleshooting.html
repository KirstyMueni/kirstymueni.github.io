Network Troubleshooting Project

Networking · Diagnostics & Inter-VLAN Routing · First-Level Support

Project Overview

Provided first-level network support by diagnosing and resolving common connectivity issues affecting users within the organization. Troubleshooting followed a systematic path — physical layer, configuration, then routing — and where connectivity between VLANs was the problem, that meant verifying inter‑VLAN routing using the Router‑on‑a‑Stick architecture.

The work paired methodical diagnostics with the configuration knowledge to fix what was found, restoring access quickly and explaining the cause so issues were less likely to recur.

Key Focus: Resolving connectivity issues through systematic, layer-by-layer diagnostics and verified routing configuration.

Key Responsibilities

  • Performed systematic network diagnostics and troubleshooting to resolve connectivity issues.
  • Configured and verified inter‑VLAN routing using the Router‑on‑a‑Stick architecture.
  • Tested reachability across subnets and VLANs.
  • Checked cabling, ports, IP configuration, and device status.
  • Provided first-level support to affected users.
  • Documented issues and resolutions for the support record.

Issues & Configurations Addressed

  • Device & User Connectivity Failures
  • Inter‑VLAN Routing (Router‑on‑a‑Stick)
  • Subnet Reachability Problems
  • IP & Port Misconfiguration
  • Physical Layer & Cabling Faults
  • Documented Incident Resolutions

Tools & Technologies Used

Cisco IOS CLI Router-on-a-Stick Ping & Traceroute Show Commands Cable & Port Testing

Diagnostics & Resolution Activities

  • Isolating faults layer by layer, from cable to routing
  • Verifying subinterfaces and encapsulation on the router
  • Confirming inter‑VLAN routing with cross‑subnet ping tests
  • Correcting IP, port, and configuration errors
  • Restoring connectivity and confirming with users
  • Logging causes and fixes for future reference

Impact & Outcomes

  • Restored connectivity for users affected by network faults.
  • Working inter‑VLAN routing enabling communication across subnets.
  • Faster resolution through a repeatable diagnostic method.
  • A support record that reduced repeat incidents.
